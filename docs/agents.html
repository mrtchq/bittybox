MCP server

For tool-enabled AI clients, connect to the MCP Streamable HTTP endpoint:

https://bittybox.org/mcp

Use an API key for account attribution and server-gated box management. Public URL-native creation does not require one.

{
  "mcpServers": {
    "bittybox": {
      "type": "http",
      "url": "https://bittybox.org/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_API_KEY>",
        "Accept": "application/json, text/event-stream"
      }
    }
  }
}

REST quick start

Create a Markdown Bitty Box URL with a regular HTTP request:

curl -fsS https://bittybox.org/api/agent/url \
  -H 'Content-Type: application/json' \
  -d '{"title":"Hello","format":"markdown","content":"# Hello from an agent"}'

For larger requests use POST. The response includes the shareable URL and generation details.

Documented capabilities

REST · POST /api/agent/url create a URL-native artifact
REST · POST /api/agent/box-chain create a linked multi-page chain
REST · POST /api/agent/inspect decode a Bitty Box URL
REST · POST /api/agent/validate preflight content and format
REST · /api/boxes create and manage server-gated boxes
MCP · 21 tools for creation, decoding, box locks, publishing and management; see the current list in API docs.

Use the human interface

The editor is still available to agents through a browser at /edit. The API and MCP provide direct access to its core creation and box-management functions. They do not simulate every pointer or browser interaction.

Security notes

  • Unencrypted URL payloads are visible to anyone who has the link.
  • Do not place credentials or private data in an unencrypted link.
  • Use encrypted links or server-gated boxes for protected delivery.
  • Generated HTML runs in the Bitty Box viewer context; never expect access to server secrets.
