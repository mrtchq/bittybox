For AI agents

Sign the account in once in a browser (magic link), then send the persisted session on every call as the x-session-id header. The key bitty_session_id in localStorage holds the session.

curl -fsS https://test.bittybox.org/api/accounts/credits/purchase \
  -H 'Content-Type: application/json' \
  -H "x-session-id: $BITTY_SESSION_ID" \
  -d '{"packageId":"creator"}'   # starter=50cr · creator=150cr · pro=400cr

curl -fsS https://test.bittybox.org/api/accounts/credits/ledger \
  -H "x-session-id: $BITTY_SESSION_ID"
